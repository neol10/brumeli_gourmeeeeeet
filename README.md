# Brumeli Gourmet — Premium Website

> *"Sua dose de felicidade."* — Gourmet Deliveries & Experiências por Tailise Brun.

Website institucional e cardápio digital interativo de alta sofisticação para a **Brumeli Gourmet**, desenvolvido com estética editorial de design studio internacional, tipografia clássica contrastante e zero aparência de template ou site gerado por inteligência artificial.

---

## ✨ Características do Projeto

- **Direção de Arte Editorial**: Tipografia refinada (*Cormorant Garamond* nos títulos display e *DM Sans* nos textos e microcópias).
- **Paleta Cromática Exclusiva**:
  - Creme: `#F8F1E5`
  - Bege: `#EADBC8`
  - Terracota: `#873D1D`
  - Marrom Profundo: `#302218`
  - Dourado Suave: `#C99753`
- **Hero Gastronômico Imersivo**: Composição editorial com transição orgânica para a fotografia principal, selo flutuante com respiração orgânica (*breathing effect*) e diferenciais reais da casa.
- **Cardápio Digital Completo (53 Produtos)**:
  - Batatas Recheadas Artesanais
  - **Configurador Dinâmico da Torre de Batatas**: Seletor interativo de pesos (400g, 700g e 1kg) e sabores (*Frango*, *Carne*, *Mista*, *Mexicano*) com cálculo instantâneo de preços reais extraídos do cardápio oficial.
  - Hot-Dogs Artesanais
  - Xis-Gaúcho Tradicional
  - Pastéis Crocantes
  - Drinks & Bebidas Autorais
  - Cafés Gourmet & Chás
  - Petiscos e Iscas
  - Download direto do cardápio original em PDF
- **Seção "Sobre" em 3 Colunas**: Inspirada em composições assimétricas editoriais (origem em marrom profundo, fotografia real do ambiente no centro e citação filosófica em bege).
- **Galeria Visual Assimétrica**: Recortes fotográficos elegantes de bolos, tortas da vitrine, sobremesas e espaço físico.
- **Animações GSAP & Microinterações**:
  - Revelação de títulos e entrada escalonada (*stagger*) via GSAP ScrollTrigger.
  - Parallax suave na fotografia principal.
  - Efeitos pulsantes sutis (*pulse-glow* e *shimmer sweep*) nos botões de conversão e atendimento.
  - Suporte completo a `prefers-reduced-motion`.
- **Responsividade Total**: Layout adaptativo para resoluções Desktop (1440px), Tablet (905px) e Mobile (390px) com menu drawer exclusivo.

## 🛠️ Stack Tecnológica

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, Server Components & Static Site Generation)
- **Linguagem**: [TypeScript](https://www.typescriptlang.org/)
- **Estilização**: [Tailwind CSS](https://tailwindcss.com/)
- **Animações**: [GSAP](https://gsap.com/) (GreenSock Animation Platform) + ScrollTrigger
- **Ícones**: [Lucide Icons](https://lucide.dev/)
- **Deploy Ready**: Otimizado para hospedagem na [Vercel](https://vercel.com/)

## 🚀 Como Executar Localmente

1. **Clone o repositório**:
   ```bash
   git clone https://github.com/neol10/brumeli_gourmeeeeeet.git
   cd brumeli_gourmeeeeeet
   ```

2. **Instale as dependências**:
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento**:
   ```bash
   npm run dev
   ```
   Acesse [http://localhost:3000](http://localhost:3000) no seu navegador.

4. **Para gerar a build de produção**:
   ```bash
   npm run build
   npm run start
   ```
